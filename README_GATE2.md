## Gate 2 scope

Adds one controlled test path to the existing picker:

`写入选中到目录 (N)`

It reuses upstream:
- picker checkboxes;
- active-branch Markdown behavior;
- attachment/image/generated-file discovery;
- attachment downloading;
- Markdown local-link generation;
- floating launcher.

It writes selected conversations through File System Access API as:
- raw JSON;
- Markdown;
- attachment/image/generated-file folder.

## Apply

1. Obtain the exact upstream `Tampermonkey.js` from commit `efa1f0f...`.
2. Run:

```bash
python ChatHarbor_Gate2_DirectoryWriter_patch.py Tampermonkey.js ChatHarbor-Gate2.user.js
```

3. Install `ChatHarbor-Gate2.user.js` in Tampermonkey.
4. Use a disposable test directory.
5. Open the existing conversation picker.
6. Select one ordinary conversation.
7. Click `写入选中到目录 (1)`.

## Acceptance

First ordinary conversation:
- JSON exists;
- Markdown exists;
- JSON conversation ID matches selected item;
- no ZIP is generated by the directory-write action;
- picker remains open.

Then one attachment-bearing conversation:
- asset folder exists;
- successful assets are present;
- Markdown links use local relative paths;
- failed optional assets are reported but do not fabricate local links.

Only after Gate 2 passes should manifest and Version-aware Scan be added.
