# ChatHarbor v0.0.14.5 — First Public Release / 首个公开发布版

Release date / 发布日期: **2026-09-20**

[中文](#中文) · [English](#english)

## 中文

v0.0.14.5 是 ChatHarbor clean-lineage 的首个正式公开发布版。

### 产品定位

ChatHarbor 是一个**本地优先的 ChatGPT 对话归档与完整性审计工具**。

它不承诺平台无法保证的“100% 完整备份”；它尽可能保存当前可取得的数据，并对已知缺口保留来源、失败阶段、原始错误和原会话核查入口。

### 本版完成

- 附件 provenance：用户上传 / ChatGPT生成交付文件 / 生成媒体 / assistant asset / unknown；
- 会话级“附件 N 未归档”提示与筛选；
- 紧凑附件详情：文件名 / 来源 / 原始错误 / 阶段；
- 403 / 404 / 415 / 500 / 下载 URL 失效的解释层，并保持原始错误为事实证据；
- 普通会话和项目会话“打开原会话”；
- SYNC_COMPLETION 与 LOCAL_PREFLIGHT 可审计报告；
- per-run 与历史累计附件状态分离；
- 独立历史 provenance Backfill / Migration Tool（默认 Dry Run）；
- Userscript 产品身份、metadata、上游 attribution 清理；
- 项目名称轻量标签与附件详情表头；
- 保留四个用户主状态：已同步 / 待同步 / 需确认 / 异常。

### 已验证

真实 Browser Smoke 已确认：

- 普通会话与项目会话原链接正确；
- 附件完整性筛选与会话详情可用；
- Provenance Dry Run 对当前历史归档重复得到 280/280 本地可识别、Unknown=0；
- Candidate 2 UI 与 metadata 清理通过；
- 自动语法、核心回归、Report、Provenance、Preflight、Layout v2、scheduler 等测试通过。

`0.0.14.2`、`0.0.14.3`、`0.0.14.4` 是经过验证的开发里程碑，但没有分别作为公开 GitHub Release 发布。它们的能力统一进入 v0.0.14.5；详见 `CHANGELOG.md`。

## English

v0.0.14.5 is the first formal public release of the ChatHarbor clean lineage.

### Product position

ChatHarbor is a **local-first ChatGPT conversation archive and integrity-audit tool**.

It does not promise a “100% complete backup” that the platform itself cannot guarantee. It preserves what is currently obtainable and records provenance, failure stage, raw errors, and original-conversation recovery paths for known gaps.

### Included in this release

- attachment provenance: user upload / ChatGPT-generated deliverable / generated media / assistant asset / unknown;
- conversation-level “N attachments unarchived” hints and filtering;
- compact attachment detail columns: file / source / raw error / stage;
- explanatory layers for 403 / 404 / 415 / 500 / expired URLs while retaining raw errors as evidence;
- “Open original conversation” for normal and project conversations;
- auditable `SYNC_COMPLETION` and `LOCAL_PREFLIGHT` reports;
- separation of per-run attachment outcomes from cumulative historical integrity state;
- standalone historical provenance Backfill / Migration Tool (Dry Run by default);
- cleaned ChatHarbor userscript identity, metadata, and upstream attribution;
- lightweight project chips and attachment-detail column headers;
- preserved four-state user model: Synced / To sync / Needs confirmation / Error.

### Validation

Real browser smoke testing confirmed:

- original-conversation links work for normal and project conversations;
- attachment-integrity filtering and conversation details are usable;
- provenance Dry Run repeatedly classified all 280 historical failure records locally with Unknown=0;
- Candidate 2 UI / metadata cleanup passed;
- automated syntax, core regression, report, provenance, preflight, Layout v2, and scheduler tests passed.

### Development milestone note

`0.0.14.2`, `0.0.14.3`, and `0.0.14.4` were validated development milestones but were not separately published as public GitHub Releases. Their capabilities are consolidated into v0.0.14.5; see `CHANGELOG.md`.
