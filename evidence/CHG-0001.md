# CHG-0001 Evidence

## Claim

The two ChatGPT exporter entry buttons are separated by a minimal generic-script-only positioning change, while their existing DOM creation and click paths remain intact.

## Root Cause

Both scripts independently append one fixed button to `document.body` in the bottom-right region. The generic script used `right: 20px; bottom: 20px; zIndex: 99999`; ChatGPT v0.4 used `right: 24px; bottom: 24px; zIndex: 99997`. The differing z-index values do not prevent geometric overlap.

## Change

Changed only the generic script's button anchor from `bottom: "20px"` to `bottom: "80px"`. Right alignment, z-index, button creation, click handler, dialog invocation, and export flow are unchanged.

## Method

- Inspected current UI creation and positioning in both scripts.
- Applied a one-line source change to `通用AI对话导出脚本.txt`.
- Ran Node syntax checks through standard input and inspected the source diff.

## Result

PASS for static syntax and structural inspection. The diff is limited to the generic button's bottom offset. The intended anchor separation is present in source, but real rendered overlap, independent clicks, downloads, and site regression remain Unknown without a ChatGPT page.
